# GlobalRoots

GlobalRoots is an interactive web application designed for students, travelers, and cultural enthusiasts who want to discover, learn about, and compare diverse cultural traditions, languages, customs, and cuisines from around the globe. The current MVP includes a searchable country atlas, community story form, and cultural knowledge quiz.

# Problem or Need
People interested in world cultures often have to dig through scattered, text-heavy encyclopedia pages or travel blogs, making it difficult to find concise, engaging, and well-organized cultural information in one place.

## Core Features

# Interactive Country Profiles
A searchable directory of nations featuring key cultural facts, traditional clothing, etiquette guides, and local holidays.

## Interactive Cultural Map
 A visual map interface allowing users to click on different regions or countries to instantly view their cultural highlights.
## Community Shared Stories/Traditions
 A feature where users can submit and read authentic personal stories or traditional recipes contributed by people from various backgrounds.

## Interactive Quiz Module
 A fun trivia section allowing users to test their knowledge of world customs, greetings, and traditions.
