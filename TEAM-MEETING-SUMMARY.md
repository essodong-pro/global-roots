## Selected Proposal

The team selected **GlobalRoots**, an interactive cultural discovery application for students,
travelers, and curious learners. Users can browse concise country profiles, learn etiquette and
traditions, read community stories, and test their knowledge with a short quiz.

We chose this proposal because it has a clear audience, a useful educational purpose, and an MVP
that can be implemented incrementally. The country directory provides an achievable first feature,
while stories, quiz content, and the cultural map give the project room to grow.
